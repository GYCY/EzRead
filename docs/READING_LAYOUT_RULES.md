# 通用论文版面识别规则

适用于所有导入论文，不依赖论文 ID、标题、DOI、学科或固定页码。规则入口是 `layout_rules.py`，几何实现是 `pdf_tools.py` / `pdf_regions.py`。单篇修复脚本不是产品识别流程，不参与导入或翻译。

## 共同顺序

1. 保留 PDF、字形、字体、坐标和原始源块；先检测页眉页脚、实际栏间空隙及阅读顺序。
2. 结合图注、表题和几何证据确定图表边界，再识别独立公式，最后恢复自然段与参考文献条目。一个区域不能同时被当作正文、插图及公式重复输出。
3. 数学编号、字体、关键词都只是证据，不能单独决定分类。每个显示对象必须有源页码和区域；无法判断时保留原文并提示待核对。
4. 所有文献使用同一规则版本。提取、阅读旧文献、全文翻译前均检查质量；质量检查不改写原文，不调用模型，也不把“没有发现问题”当成绝对正确。

## 分类与反例

| 类型 | 自动确认所需证据 | 必须避免的误判 | 显示与翻译 |
| --- | --- | --- | --- |
| 正文自然段 | 同栏阅读顺序、基线、行距、首行缩进及语句连续性 | PDF 换行/换页直接成为新段；数学字体占比高就变成公式 | 保留完整段落；源锚点可跨块或跨页 |
| 项目列表 | 项目符号或序号与缩进对应；续行归属同一项 | 一个短词单独成为项目；把相邻项目合并 | 每项一个段落 |
| 段内公式 | 变量/等式属于句子的语法与行内位置 | 含 `=`、希腊字母或数值就裁图 | 随句保留；不可解码符号提示核对，不编造符号 |
| 独立公式 | 数学主体与独立排版；有编号时核对同栏、同行/多行关系 | 正文中的“见式 (3)”；文献年份；表格数值 | 完整原图包含主体、分母、上下标、续行和编号；邻近编号限制归并范围 |
| 插图 | 图形对象、图注和实际栏界一致；单栏或跨栏须有版面证据 | 把邻栏公式横线或正文吸入图像；遗漏图注 | 保留完整图，图注作为文本翻译 |
| 表格 | 表题、边线/表头与数据对齐共同确定范围 | 只有表题截图；按正文栏顺序串读单元格；漏空格/单位/空单元格 | 原表保留；全文翻译处理表题、表注与单元格，点击仅展开结果 |
| 参考文献 | 先进入参考文献区域，再识别 `[1]`、`1.`、`1)` 或作者年份开头；悬挂续行合并 | 正文作者年份被当作条目；多篇串成一段；附录继续算参考文献 | 每篇独立一段，保持原文与引文信息 |

表题/图注识别支持阿拉伯编号、罗马编号、补充材料编号（如 S2）、英文常见缩写及中文“图/表”标签。这不意味着所有语种、任意复杂表格都已可靠支持。

## 表格约束

- 有框线表按行列线定位；三线表以列标题与数据行起点定位，多行单元格不能被拆成多行记录。
- 复合表头只有在数据行间存在一致的空白列缝时才细分。跨页表、多级合并单元格、无框线表和扫描表无法确认时标记待核对；当前不自动 OCR。
- 翻译采用全文任务冻结的模型配置，检查行列数量、空单元格、数值和单位。暂存结果，完成后发布；重译保留旧版本，取消或来源变化不能覆盖新内容。
- 没有可靠行列时仅有表题译文不能称作“表格内容翻译完成”。界面必须明确提示内容待核对。

## 已有文献

旧文献也使用当前质量检查，标记旧版提取、表题无区域、表格行列不明、公式无来源、图与公式重叠等问题。检查入口重新运行同一提取器；只对来源匹配可靠的候选应用覆盖层。不能因升级就静默替换全库的源块、手工修订、译文或批注。

当前全文翻译前自动执行的是质量检查，不是全库重提取迁移。已保存的错误源块仍须经来源核对后修复；不能把规则更新等同于所有旧数据都已修好。

## 验收

`tests/test_layout_rules.py` 使用独立合成 PDF，覆盖不同页面宽度、三线表、罗马/补充编号、参考文献样式、附录结束边界与质量检查只读性。`tests/test_reader_quality.py` 覆盖单栏编号公式、多行分式、双栏图与公式隔离、段内参数、列表、表格数值校验及全文翻译中的表格处理。浏览器回归核对展开不发翻译请求、窄窗和保存恢复。

每次发现新误判，补充不含私人论文的最小合成样例与反例，再修改共享规则。没有独立验证的版式明确记录为待支持，不能仅凭某篇修复成功推断所有论文可靠。
